# Conversion Copy Studio
A small workshop for marketing copy: a live copy checker, a headline idea generator, and before-and-after rewrite studies.

The brands in the rewrite studies are **fictional practice examples**, not client work.

## Copy checker
Looks at reading ease, sentence length, "you" versus "we" focus, specific numbers, call to action, weak words and exclamation marks. These are guidelines for editing, not proof that copy will convert.

## Run
`npm install` then `npm run dev`. Build with `npm run build`. Deploy to Vercel or run `npm run deploy` for GitHub Pages.
